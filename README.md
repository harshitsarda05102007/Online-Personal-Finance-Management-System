# Online Personal Finance Management System

A web-based personal finance tracker designed to monitor daily income, expenses, category-wise budgets, and user access with security audit logs.

## 🚀 Features
- **User Dashboard**: Real-time overview of total outflow, active budget, and recent transactions.
- **Expense Ledger**: Add, categorize, and track daily spending.
- **Role-Based Access**: User and Administrator role separation.
- **Admin Audit Trail**: Track user activities and authentication events.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP 8.x
- **Database**: MySQL / MariaDB

## ⚙️ Installation & Setup
1. Clone or copy the project folder to your local server directory (`htdocs` for XAMPP).
2. Start **Apache** and **MySQL** from XAMPP Control Panel.
3. Open `http://localhost/phpmyadmin` and import `database/finance_management.sql`.
4. Run the project in your browser: `http://localhost/online-personal-finance-management/`.
